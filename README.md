# Crop Recommendation and Climate Analysis using Power BI

This project analyzes agricultural data to understand the relationship between soil nutrients, climate conditions, and crop suitability.

Tools Used:
- Power BI
- Crop Recommendation Dataset

Features:
- Crop distribution visualization
- Temperature, rainfall, humidity analysis
- Soil nutrient analysis (N, P, K)
- Interactive crop filtering

Dataset Source:
Kaggle Crop Recommendation Dataset
